# Milestone 01 — Foundation

## Goal

Create the technical foundation for Nova AI.

This milestone is only responsible for project initialization and developer tooling.

No business logic should be implemented.

---

## Scope

Included:

- Next.js 15
- React 19
- TypeScript
- pnpm
- Tailwind CSS v4
- shadcn/ui
- ESLint
- Prettier
- Husky
- lint-staged
- Prisma
- PostgreSQL configuration
- Better Auth installation (configuration only)
- TanStack Query
- Motion
- React Hook Form
- Zod
- Docker
- Environment variables
- Path aliases
- Folder structure

---

## Not Included

- Authentication
- Dashboard
- Chat
- Image Generation
- Video Generation
- Credits
- Billing
- Admin Panel
- Database models
- API integrations

---

## Acceptance Criteria

- Project runs successfully.
- No TypeScript errors.
- No ESLint errors.
- Dark mode configured.
- Folder structure created.
- Prisma initialized.
- Docker configured.
- Ready for Milestone 02.
