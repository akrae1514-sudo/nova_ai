# Milestone 02 — App Shell

## Goal

Build the main application shell for Nova AI.

This milestone establishes the reusable layout used across the authenticated application.

No business logic should be implemented.

---

## Scope

Implement:

- Main application layout
- Responsive sidebar
- Top navigation bar
- Logo placeholder
- Navigation menu
- User menu placeholder
- Credits indicator placeholder
- Main content area
- Mobile navigation
- Dark theme polish
- Design tokens
- Reusable layout components

---

## Navigation

Sidebar items:

- Chat
- Images
- Videos
- History

Bottom section:

- Settings

Top bar:

- Model selector placeholder
- Credits placeholder
- User avatar placeholder

---

## Routes

Create empty pages only:

/chat
/images
/videos
/history
/settings

Each page should contain only a temporary heading.

---

## Not Included

- Authentication
- Chat functionality
- AI providers
- Image generation
- Video generation
- History logic
- Billing
- Credits system
- Admin dashboard

---

## Acceptance Criteria

- Fully responsive layout
- Sidebar collapses on mobile
- Navigation works
- Dark theme polished
- Reusable layout components
- Ready for Chat implementation
